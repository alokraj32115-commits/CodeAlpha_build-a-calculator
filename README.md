
Task 2: Build a Calculator
## Objective
Create a basic calculator using HTML, CSS, and JavaScript that performs arithmetic operations and provides a simple, user-friendly interface.
Description
The Calculator Web Application allows users to perform basic mathematical calculations such as addition, subtraction, multiplication, and division. It includes an interactive display screen, calculator buttons, and real-time result calculation. The application is fully responsive and works smoothly on desktop, tablet, and mobile devices.
## Features
Basic arithmetic operations (+, −, ×, ÷)
Interactive display screen
Number and operator buttons
Clear (C) button
Delete (⌫) button
Real-time result display
Responsive user interface
## Technologies Used
HTML5
CSS3
JavaScript (ES6)

calculator/

## How to Run
Download or clone the project.
Open the project folder.
Open index.html in any web browser.
Use the calculator to perform calculations.
